# Stage 2 — Intermediate Python

This stage focused on advanced Python features, modular programming, standard library tools, file handling, data formats, and database concepts.

## Topics Covered

### Object-Oriented Programming (OOP)

- Classes and Objects
- Inheritance and Polymorphism
- Encapsulation
- `super()`
- Multiple Inheritance and Mixins
- Class Methods and Static Methods
- Properties and Access Conventions
- Magic/Dunder Methods
- Duck Typing

### Python Standard Library

- `collections`
  - `Counter`
  - `defaultdict`
  - `deque`
- `itertools`
  - `combinations`
  - `permutations`
  - `product`
  - `chain`
  - `islice`
- `functools`
  - `partial`
  - `reduce`
  - `lru_cache`

### Advanced File Operations

- File modes and reading/writing
- Context managers (`with`)
- `seek()` and `tell()`
- Binary files
- `pathlib` for file and directory management

### Data Formats

- JSON parsing and serialization
- XML parsing using `ElementTree`

### Configuration

- INI configuration files
- YAML configuration files

### Databases

- Basic SQL concepts
- SQLite with Python
- Basic CRUD operations

## Key Learning

Gained an understanding of intermediate Python concepts and their applications in real-world development, including OOP, data processing, file management, configuration handling, and database interaction.
