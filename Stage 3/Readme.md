Python Concepts: Generators, Decorators & Context Managers

This repository explains three important Python concepts:

Generators

Generators are used to produce values one at a time instead of storing all values in memory at once.

Key idea: Efficient and memory-friendly data processing.

Decorators

Decorators are used to add or modify functionality of an existing function without changing its original code.

Key idea: Reusable behavior such as logging, authentication, and validation.

Context Managers

Context managers are used to manage resources safely and ensure proper cleanup after use.

Key idea: Setup and cleanup of resources such as files, database connections, and locks.

Summary
Generator → Produces values efficiently.
Decorator → Adds functionality to functions.
Context Manager → Manages resources safely.
