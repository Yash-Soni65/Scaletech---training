# User and Role Management API

## Introduction

The **User and Role Management API** is a Django-based backend application developed to manage users, roles, and access modules.

The project provides CRUD APIs for users and roles, user signup and login, session-based authentication, role-based access control, module management, user searching, and bulk user updates.

The API is implemented using **Django Function-Based Views and `JsonResponse`** without using Django REST Framework.

---

## Features

* User CRUD APIs
* Role CRUD APIs
* User signup with a default `User` role
* User login using email and password
* Django session-based authentication
* Password hashing using Django's built-in authentication system
* Role-Based Access Control (RBAC)
* Add and remove access modules from roles
* Check user access to a specific module
* Search users by first name, last name, or email
* Search roles by role name
* Bulk update multiple users
* Input validation and error handling
* SQLite database for development

## API Endpoints

### Roles

| Method   | Endpoint                           | Description     |
| -------- | ---------------------------------- | --------------- |
| `GET`    | `/roles/`                          | List roles      |
| `POST`   | `/roles/`                          | Create a role   |
| `GET`    | `/roles/<role_id>/`                | Retrieve a role |
| `PUT`    | `/roles/<role_id>/`                | Update a role   |
| `DELETE` | `/roles/<role_id>/`                | Delete a role   |
| `POST`   | `/roles/<role_id>/modules/add/`    | Add a module    |
| `POST`   | `/roles/<role_id>/modules/remove/` | Remove a module |

### Role Search

```text
GET /roles/?search=admin
```

### Users

| Method   | Endpoint                          | Description         |
| -------- | --------------------------------- | ------------------- |
| `GET`    | `/users/`                         | List users          |
| `POST`   | `/users/`                         | Create a user       |
| `GET`    | `/users/<user_id>/`               | Retrieve a user     |
| `PUT`    | `/users/<user_id>/`               | Update a user       |
| `DELETE` | `/users/<user_id>/`               | Delete a user       |

## Authentication

The login API authenticates users using their email and password.

```text
POST /users/login/
```

Example request:

```json
{
    "email": "alex@example.com",
    "password": "StrongPassword123"
}
```

After successful login, Django creates a session for the authenticated user.

The signup API creates a new user and assigns the default `User` role.

```text
POST /users/signup/
```

---

## Role-Based Access Control

Users are assigned to roles, and each role contains a list of access modules.

Example:

```json
{
    "roleName": "Admin",
    "accessModules": [
        "users",
        "roles",
        "reports"
    ],
    "active": true
}
```

Module access is checked through the user's assigned role:

```text
User
  ↓
Role
  ↓
Access Modules
  ↓
Requested Module
  ↓
Access Granted / Denied
```
